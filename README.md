## What is Resonare Worship Stage?

Resonare Worship Stage is the control room for a worship service. The **desktop app** runs the service from the booth — building the running order, sending slides to the screen, and driving stage and audience outputs — while a **phone or tablet companion** lets the team control and follow along from anywhere in the room.

It is designed to feel modern and premium, with a dark-first interface, polished loading and empty states, and a fast live workflow built for real Sunday-morning pressure.

### Two surfaces that work together

- **Desktop operator app** (Windows / macOS) — the main control surface for planning and running services.
- **Mobile / tablet companion** — a web companion that connects to the same organization and live session for remote control and on-stage confidence display.

Both stay in sync through a shared cloud live session, so what the operator does on the desktop instantly reflects on every connected device.

---

## Key features

- **Service planning and live control** — build a running order of songs, scripture, media, and custom items, then take slides live with a dedicated Run Service operator view and slide preview.
- **Audience output** — a fullscreen presentation screen with second-display support that shows only the current slide content for a clean congregation view.
- **Stage display** — a separate, text-only confidence screen for the platform, with an organization-level layout editor.
- **Song library** — a section-based song editor (verse, chorus, bridge, etc.) with reusable templates and generated slide previews. No CCLI/SongSelect lock-in.
- **Scripture flow** — official Bible passages for **NLT** (English) and **NTV** (Spanish), with clean verse formatting and paragraph-style slides.
- **Media library** — image and video backgrounds with upload status states and a custom in-app preview player; per-item background with loop/mute controls.
- **Mobile companion** — phone/tablet **Remote Control** (next/previous slide and item) and a fullscreen **Stage Screen** confidence view.
- **Lighting control** — optional stage lighting from the app via Home Assistant, including manual per-light control and automated lighting cues tied to service separators.
- **Bilingual throughout** — full English and Spanish interface.
- **Built-in updates** — the desktop app can check for new versions in **Settings → App** and download the installer for you when an update is available.

## Downloads and installation

Open **[Releases](https://github.com/mmorera-25/resonare-worship-stage-releases/releases)** and download the latest version for your platform:

| Platform | File |
|----------|------|
| Windows (64-bit) | `Resonare Worship Stage-<version>-Setup-x64.exe` |
| macOS (Apple Silicon) | `Resonare Worship Stage-<version>-arm64.dmg` |

Notes:

- **Windows:** during development builds are unsigned, so Windows SmartScreen may warn before installing. Choose **More info → Run anyway** if you trust the source.
- **macOS:** open the `.dmg` and drag the app to **Applications**. If macOS blocks the first launch, allow it under **System Settings → Privacy & Security**.
