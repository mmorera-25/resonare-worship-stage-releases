# Resonare Worship Stage — Desktop downloads

This repository publishes **installers only** for [Resonare Worship Stage](https://resonare-worship-stage.web.app), a worship presentation and live-service control app for churches and worship teams.

Source code is maintained separately and is **not** published here.

## About the app

Resonare Worship Stage helps operators run services with:

- Service planning and slide control
- Audience and stage outputs
- Scripture, songs, and media
- Companion control from phone or tablet (PWA)
- Integrations such as Home Assistant for lighting (where configured)

The **desktop app** is the main control surface. The **mobile companion** works alongside it on the same organization and live session.

## Development status

**This product is in active development.** Builds on this page are early releases for testing and private use. Features, stability, and installer signing may change between versions.

Please expect occasional breaking changes and use caution in live environments until a stable release is announced.

## Accounts and access

- **New account registration is invitation-only.** Public sign-up is disabled while the product is in development.
- If you downloaded an installer but do not have an account, you will not be able to sign in until you receive an invitation from the developer or your organization administrator.
- Existing invited users can sign in with the credentials they were given (email/password or Google, as enabled for their account).

## Downloads

Open **[Releases](https://github.com/mmorera-25/resonare-worship-stage-releases/releases)** and choose the latest version:

| Platform | File |
|----------|------|
| Windows (64-bit) | `Resonare Worship Stage-{version}-Setup-x64.exe` |
| macOS (Apple Silicon) | `Resonare Worship Stage-{version}-arm64.dmg` (or similar `.dmg` on the release) |

The desktop app can also check for updates in **Settings → App** and download installers to your **Downloads** folder when a newer version is available.
