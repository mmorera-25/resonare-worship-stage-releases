# Resonare Worship Stage

A bilingual (English / Spanish), cloud-first worship presentation and live-service control platform for churches and worship teams.

Resonare Worship Stage is the control room for a worship service. A **desktop app** runs the service from the booth — building the running order, sending slides to the screen, and driving stage and audience outputs — while a **phone or tablet companion** lets the team control and follow along from anywhere in the room. Both stay in sync through a shared cloud live session, so what the operator does instantly reflects on every connected device.

It is designed to feel modern and premium, with a dark-first interface, polished loading and empty states, and a fast live workflow built for real Sunday-morning pressure.

---

## Two surfaces that work together

- **Desktop operator app** (Windows / macOS) — the main control surface for planning and running services.
- **Mobile / tablet companion** — connects to the same organization and live session for remote control and an on-stage confidence display.

---

## Features

- **Service planning and live control** — build a running order of songs, scripture, media, and custom items, then take slides live with a dedicated Run Service operator view and slide preview.
- **Audience output** — a fullscreen presentation screen with second-display support that shows only the current slide for a clean congregation view.
- **Stage display** — a separate, text-only confidence screen for the platform, with an organization-level layout editor.
- **Song library** — a section-based song editor (verse, chorus, bridge, and more) with reusable templates and generated slide previews.
- **Scripture flow** — official Bible passages for **NLT** (English) and **NTV** (Spanish), with clean verse formatting and paragraph-style slides.
- **Media library** — image and video backgrounds with upload status states and a custom in-app preview player; per-item backgrounds with loop and mute controls.
- **Mobile companion** — phone/tablet **Remote Control** (next/previous slide and item) and a fullscreen **Stage Screen** confidence view.
- **Lighting control** — optional stage lighting through Home Assistant, including manual per-light control and automated cues tied to service separators.
- **Bilingual throughout** — full English and Spanish interface.
